# Boss 客户商机切入判断

基于目标公司当前公开的 Boss 岗位与完整 JD，生成一份给销售使用的、证据受限的商机切入报告。

## 适用场景

- 输入公司名称，判断本轮可推的产品、优先联系的业务职能和首场会目标。
- 使用蝉妈妈产品组合时，只有客户业务动作、产品可提供的材料和可联系职能同时成立，才提出销售入口。

不用于业务战略或人才战略报告，也不把招聘岗位当作预算、采购意向或成交概率。

## 输入与产出

输入：公司名称；可选我方产品上下文和报告目录。

输出目录包含：

- `opportunity-entry-report.md`：面向销售的商机切入报告
- `analysis-input.json`：本次岗位快照
- `evidence-map.json`：证据与判断附件
- `manifest.json`：交付清单

## 启动示例

`$boss-company-opportunity-entry 特步`

## 运行边界

首次使用需要用户在本技能专用 Chrome 中完成 Boss 登录。页面出现访问受限、账户异常行为、安全验证或登录失效时，采集会保留断点并暂停，等待用户在前台恢复后再从原命令续跑。
